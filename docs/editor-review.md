## 已修复的评审问题

- 首次无发布时错误显示 v0 正在下载：改为尚未发布，明确设备暂不可下载。
- 放弃草稿无法恢复已改过的秘密 URL：改为服务端快照恢复，完整恢复秘密字段。
- 仅修改 URL 时配置差异不明显：展示脱敏的新旧值增删行，不输出地址或秘密摘要。
- 保存成功后发布按钮保持禁用：异步操作结束重新渲染并恢复控件。
- 生成失败时差异容易误解为全部删除：明确提示先修复字段或引用问题。
- 导入错误类型可能被默认值覆盖：显式拒绝错误类型和多文档 YAML。
- 历史比较可能没有加载配置：打开比较前获取相应脱敏工件。
