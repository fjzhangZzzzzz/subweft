# 首版支持矩阵

基准：ADR-0008，2026-10-30 本机验收候选。所有日常编辑均为结构化表单。

| 对象 | 已实现 | 不支持 |
|---|---|---|
| 订阅 | URL、可读名称、启用、一个池、更新间隔、前缀、健康检查、拉取代理 | 服务端抓取、节点编辑、手工代理 |
| 策略组 | select / url-test、一个或两个池、DIRECT / REJECT、测试 URL/间隔/容差 | 嵌套、逐节点选择、其他组类型 |
| 自维护规则集 | 按用途命名，完整域名/子域名/IPv4/IPv6 CIDR 混合，批量添加 | 任意 classical 表达式 |
| 远程规则集 | HTTP(S)、YAML、domain / ipcidr、更新间隔 | file、mrs、text、classical、服务端缓存 |
| 分流规则 | RULE-SET、DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD、IP-CIDR、GEOIP；顺序、目标、适用的 no-resolve；最后 MATCH | 任意逻辑/脚本规则 |
| 发布 | 持久草稿、修订冲突、脱敏 Git 风格差异、原生检查、显式发布、最近 20 版、恢复到草稿 | 自动发布、直接切换历史活动指针 |
| 设备 | 新增/命名/到期/暂停/恢复/撤销/换链接、最近下载 | Nginx token 管理、每设备配置、在线状态 |
| 身份 | 部署指定的唯一 OIDC issuer + sub、会话和 CSRF | 首次登录自动管理员、用户/角色页面 |
| 基础配置 | 端口等首次导入后只读；DNS 开关、IPv6、解析模式、上游服务器、域名策略、后备筛选、Fake-IP 范围/例外、hosts；clash-config DNS 预设 | YAML 编辑器、任意运行时高级字段编辑 |

首次导入仅接受明确支持的单文件子集（[示例](examples/editor.yaml)），未知字段、错误类型、手工节点和文件规则集明确拒绝。按订阅在策略组中的相同引用关系推导两个池；超过两个不同引用组合时拒绝导入。导入后必须审阅两个池的业务含义。客户端缓存 path 由服务重新生成，inline 集合按类型生成可读 provider 名称。不会擅自合并原配置中交错排列的集合。

配置检查验证渲染定义；HTTP provider 内容由客户端下载，不验证远端节点或远端规则。GEOIP 的 Country.mmdb / GeoIP.dat、DNS 地理规则的 GeoSite.dat 为可选校验条件。缺库时执行已识别位置的投影检查并显示未验证；原始发布规则不变。指定数据库检查失败仍阻止本次检查，不静默降级。顶层 GEOSITE 表单及任意逻辑表达式仍不在支持范围。

本机 Windows 开发检查使用锁定 Mihomo；Linux 生产隔离沿用受限进程边界；候选容器验证结果以对应 CI 为准，真实客户端仍待人工验收。

订阅拉取代理为可选字段：默认“跟随客户端路由（不指定）”，渲染时省略 `proxy`；`DIRECT` / `REJECT` 和策略组为显式指定。导入保留缺省状态，不将其转换为 DIRECT；已有显式设置不自动修改。客户端规则模式下未指定的下载会参与分流，需确保订阅的启动下载路线可用，避免依赖尚未加载的自身节点。
