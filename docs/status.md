# 当前能力与验收边界

**[v0.1.0-rc.3](https://github.com/fjzhangZzzzzz/subweft/releases/tag/v0.1.0-rc.3) 已发布，供完整人工验收。** 使用[验收入口](human-acceptance.md)体验；[设计](design.md)和[支持矩阵](support-matrix.md)仍是范围依据。候选不是生产部署或替代完成的声明。

## 已实现

- 结构化 Web 表单维护来源、13 协议手工节点、多来源/标签/节点/组组合、四种策略组、规则集、规则顺序及逻辑条件、完整 DNS/policy/fallback 和客户端参数。高级字段同样使用表单，不提供原始 YAML 编辑兜底。字段按固定 Mihomo 契约严格校验，未知输入明确拒绝。
- HTTP/本地来源、provider YAML、完整配置节点提取、约定 URI/Base64；逐来源超时/重试/HTTP(S) CONNECT 代理、请求头、定时抓取、失败缓存。独立身份覆盖本地名称、排除及备注，歧义阻止套用，缺失覆盖可清理。
- 通用配置导入：仅接收标准完整配置，预览后原子创建草稿；保留显式成员、规则及 DNS 顺序，不推断部署方模板或文件布局。
- Go、加密 SQLite、独立主密钥、单实例锁；不可变配置和资源、原子活动指针、手动发布、历史回滚、基于已发布定义的自动更新，失败保留最后有效发布。来源、provider、规则及 geodata 均不在下载时同步抓取。
- 配置、provider、规则集及 geodata 绑定设备和具体发布，资源按内容摘要冻结。设备改绑、暂停/恢复、到期、再次复制、轮换、吊销；旧链接失效不会收回已下载的代理凭据。
- OIDC PKCE/state/nonce、CSRF、本地会话与退出；引导管理员、使用者角色和方案授权。普通使用者只维护自己的获授权设备；本应用停用/撤权即时影响管理和后续下载。身份服务离线不阻止冷启动和已有设备下载。
- 在线一致性加密备份；真实 CLI 从同一备份和匹配密钥恢复到新目录，拒绝覆盖已有状态。Linux 双架构运行、隔离和恢复；只读无特权 Compose、Secret 文件及基础 Nginx 示例。版本、commit、dirty 和平台可查询。
- 应用候选打包保留来源、清单、逐文件摘要及依赖许可，不携带 Mihomo、测试发行者、私有数据或密钥。公开镜像及生产实例没有发布/部署。

工作台重设计已在真实应用中验证：新建配置明确选择成员、规则短表单后直接应用、组改名同步引用、空组失败保留活动发布、创建设备后直接显示使用链接。新订阅保存后自动获取节点；客户端更新与健康检查设置保存回读通过；配置内创建规则集、返回规则选择并直接应用通过。发布归档浏览器复验无 JavaScript 错误。390×600 长弹窗保持标题与保存操作可见；Esc 和点外部支持关闭，未保存修改有确认。

应用源码 `072b88f` 已通过[三平台原生 CI](https://github.com/fjzhangZzzzzz/subweft/actions/runs/40687927825)：Windows amd64、Linux amd64、Linux arm64。三个归档均验证逐文件摘要、实际业务与一致性恢复；Linux 同时验证容器隔离。Release 的 VERIFICATION.json 固定源码、CI、摘要和基准。本机验收预览运行发布中的 Windows 归档二进制。

测试覆盖 13 协议代表参数及传输、插件字段契约、provider/规则/GEOIP/完整 DNS/逻辑规则组合、过滤/空组/循环、迁移原子性、覆盖歧义、自动更新冻结定义、资源跨方案与撤权、普通使用者越权、错误密钥和一致性备份。Linux 容器保持全部 capability 丢弃、专用 AppArmor/seccomp、只读根、tmpfs 校验、文件/网络 namespace、96 进程硬限制；宿主文件和回环访问探针通过。

浏览器原有主要闭环通过：迁移预览/创建/抓取/发布，来源高级设置及刷新保留覆盖，手工节点创建和编辑，规则新增/复制/批量启停/删除，保存/脱敏预览/发布/回滚，设备复制/暂停/恢复/改绑/轮换，使用者授权及普通身份入口，中英文、主题与 390px 布局。未出现应用 JavaScript 运行异常。所有参数组合或每种协议的真实连接不据此推导通过。

## 性能

以下为上一候选版的合成基准；本版对应结果和来源见发布资产 VERIFICATION.json。

固定场景：实际应用进程，通过 HTTP/OIDC API 抓取 10 来源、2000 节点及 30 万条合成 domain 规则，发布 5 方案、20 设备；稳定 30 秒后执行 200 次、10 并发缓存下载。配置正文 5793 字节（节点由版本化 provider 分发），另下载 20 次资源、合计约 8.5 MB；随后实际 CLI 恢复并重启，对比全部设备配置及资源。

| 原生平台 | 应用空闲 RSS | 配置下载 P95 | 应用峰值 RSS | Mihomo 子进程峰值 | 容器总峰值 |
|---|---:|---:|---:|---:|---:|
| Linux amd64 容器 | 58.51 MiB | 9.85 ms | 78.54 MiB | 59.75 MiB | 172.13 MiB |
| Linux arm64 容器 | 50.15 MiB | 11.31 ms | 77.77 MiB | 31.59 MiB | 138.69 MiB |
| Windows CI 原生进程 | 51.58 MiB | 24.98 ms | 82.14 MiB | 未测 | 不适用 |

本机 Windows 另外以同源码、本地 Go 工具链生成的实际归档复验：空闲 55.91 MiB、峰值 81.50 MiB、P95 28.15 ms，下载零失败且 CLI 恢复重启通过。

场景达到空闲 ≤64 MiB、缓存配置 P95 ≤300 ms 的门槛，下载失败为 0。Linux core 峰值来自私有启动器 wait4；整个校验任务峰值（含启动器/fork）另记录，不能把它当纯 core RSS。容器总峰值来自 cgroup，包含测试发行者、Python 驱动及恢复进程；应用数字排除这些进程。不同阶段的峰值不能相加。结果是本机/免费 runner 合成基准，不包含外网延迟、客户端资源抓取总耗时或实际代理连接承诺。[复现方法](running.md#linux-开发隔离与完整性能复现)。

## 剩余人工验收与切换边界

- 真实 Pocket ID / Passkey 登录、退出及第二身份角色隔离。测试发行者不等于真实 IdP。Pocket ID 自身撤权不替代本应用即时停用/移除授权。
- 本机 Clash Verge 首次导入、同 URL 刷新、方案改绑、新链接替换、重复配置处理及真实代理连接。
- 部署方实际配置导入语义对照；未知字段、内核版本差异须解决后再切换。
- 浏览器保存备份文件：HTTP 快照、实际 CLI 恢复和重启已验证；本机自动化浏览器连纯文本下载也被取消，未将该工具结果宣称为浏览器保存通过。
- 生产主机、新子域名及已有 ACME/Nginx 的正式接入、接入与切换。当前均未执行，旧服务保留作回退。

Windows 仅用于开发/本地试用，不具备 Linux 命名空间隔离。源码已提交、已推送、候选已构建/发布、生产已部署和人工已验收须分别记录。
