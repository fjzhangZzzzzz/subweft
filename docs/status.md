# 当前能力与验收边界

当前是可本地运行的开发预览：六种协议的来源/手工节点 → 多来源策略组 → 域名/IP规则 → 固定Mihomo校验 → 原子发布 → 独立设备下载。具体字段以[矩阵](fields.md)为准，完整目标仍见[首版支持矩阵](support-matrix.md)。

## 已实现

- Go服务、加密SQLite对象及发布快照、独立主密钥、初始化/迁移、单实例文件锁及重启持久化。
- OIDC管理员准入、PKCE/nonce/state、会话、CSRF、退出；管理端无免登录入口。
- HTTP来源及本地provider YAML、混合代理URI/单层Base64导入、严格类型校验、SSRF地址限制、有界抓取与定时快照更新。
- 订阅/手工节点/方案/组/规则/设备的相应表单，以及发布、20版本历史、回滚、复制、停用、轮换和吊销。
- ss、vmess、vless、trojan、http、socks5的明确字段；适用TLS、WS/gRPC及VLESS Reality，全部有表单。节点列表只含非敏感摘要，编辑显式读取凭据；预览覆盖新凭据类型。
- 通过锁定归档及程序SHA256识别的Mihomo v1.19.33独立原生校验；不直接Go链接其源码。
- 中英文、主题、只读脱敏预览、组成员预览、来源节点分页及表单修改保护。

## 自动化与本地验证

自动化测试覆盖严格解析、标量类型、环回/重定向抓取限制、引用与循环、失败缓存、非法发布保留当前版本、过期候选发布、独立设备撤权和轮换、OIDC/CSRF、密钥错误及真实数据库副本恢复。新增测试覆盖多协议URI、嵌套选项、ALPN空列表语义、编辑凭据隔离及列表/预览脱敏。原生校验测试需要先取得锁定程序，未取得时明确跳过。

浏览器验收使用独立本地测试OIDC发行者和文档IP来源，验证原有SS闭环，以及多协议导入、VLESS TLS/WS表单、混合成员发布和字段错误定位；不等同真实Pocket ID、Passkey或Clash Verge验收。具体逐次证据留在受限输出或CI，不在此文复制瞬时资源采样。
