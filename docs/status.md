# 当前能力与验收边界

当前仍为开发版本，完整首版验收正在推进。产品行为见[设计](design.md)，字段依据见[字段矩阵](fields.md)。公开源码不表示已经发布、部署或替代生产服务。

## 已实现

- Go、加密 SQLite、独立主密钥、单实例锁；业务快照、不可变配置、资源及原子活动指针。历史摘要使用加密索引，管理列表不重复读取完整发布正文。
- OIDC PKCE/state/nonce、CSRF、会话与退出；引导管理员、管理员维护的使用者及方案授权。普通使用者只管理自己的设备；停用账号和移除授权即时影响管理与下载。
- 13 种协议的固定版本字段与嵌套参数、严格 YAML/JSON 类型、未知字段检查、表单及导入渲染。完整目录见[契约](../internal/fields/catalog.json)；列表和预览按敏感字段脱敏。
- HTTP/本地来源、provider YAML、显式完整配置节点提取、常见 URI 与 Base64；SSRF、DNS/重定向检查、超时/重试/HTTP(S) CONNECT 代理、定时抓取及失败缓存。本地名称、排除和备注使用独立稳定身份，歧义不自动套用。
- 多来源/标签/手工节点/组引用，四种策略、过滤、成员预览、引用及循环检查。客户端 provider 的版本化节点资源和健康检查与服务端抓取分开。
- 自建/HTTP 规则集（domain/ipcidr/classical，YAML/text）、受管理 MMDB/GeoIP/GeoSite 文件、规则顺序/搜索/复制/批量/启停、AND/OR/NOT 条件。DNS 高级字段、有序 policy 及原模板全局参数均有结构化表单。
- 手动校验发布、回滚、基于已发布定义的自动更新，失败保留现行版本。配置、provider、规则和地理数据下载均绑定设备及发布。
- 设备改绑、暂停/恢复、到期、轮换、吊销及再次复制；最近下载不代表已应用或连接成功。
- 在线一致性 SQLite 备份、空数据库目录恢复及独立主密钥验证。Linux 校验使用 bubblewrap 文件/网络命名空间及进程资源限制，不可用时拒绝校验。

## 已有验证

Windows 本地 Go 测试及固定 Mihomo v1.19.33 样例通过，包括 13 协议代表样例及 provider、规则集、GEOIP、完整 DNS、逻辑规则组合。测试还覆盖资源冻结/跨方案/撤权、自动更新不激活草稿、覆盖歧义、用户越权和一致性备份恢复。

这些是渲染和配置校验证据，不代表所有参数组合或真实代理连接成功。Linux amd64/arm64 已加入原生 CI，隔离及运行结果须等对应检查通过；不从 Windows 推导 Linux 通过。
