# 当前能力与验收边界

0.2.0-rc.1 候选实现及代码复审完成，待平台验证与工件发布。统一更新方向及升级约束见 [ADR-0007](adr/0007-device-managed-updates.md)，人工流程见 [验收入口](human-acceptance.md)。

## 能力

- 远程订阅、规则及地理数据统一由设备更新；配置内选择订阅及规则更新出站，默认直连。共享订阅支持请求头、筛选、名称替换及健康检查。服务器不获取远程节点，不自动发布。
- 保留本地订阅、13 协议手工节点表单、多订阅/标签/节点/子组组合、四种策略组、规则列表与逻辑条件、DNS 和高级客户端参数。远程节点的协议解析由设备内核负责，本地字段契约独立维护。
- 发布冻结定义及本地内容，回滚不恢复远程缓存。授权设备取得上游地址及必要请求头；普通元数据、预览和错误脱敏。吊销阻止后续服务下载，不能收回已取得的上游凭据。
- 加密 SQLite 与独立密钥、OIDC、角色授权、设备改绑/暂停/到期/轮换/吊销、一致性备份及恢复继续保留。数据库版本 3 事务迁移；回退使用匹配的升级前数据库、程序与密钥。
- 旧按节点身份保存的远程覆盖或服务端代理不能静默丢失，受影响配置需通过表单处理。无关配置不受阻断。

## 验证范围

已通过本地 Go 回归、前端构建和新增固定 Mihomo 设备集成测试：直连与独立代理下载、完整配置 YAML 提取、失败保留缓存、地址变更及同目录回滚。隔离原生校验不访问上游，也不把验证投影写入发布。

真实 Playwright UI 已验证订阅请求设置往返、旧覆盖处理与转换、出站循环报错及修正发布、远程规则创建、设备链接掩码与暂停/恢复/轮换、弹窗退出确认，以及手机和桌面主页面布局。Windows 独立性能复验包含 30 万条本地规则，200 次并发下载零失败，P95 约 21 毫秒；CLI 备份恢复重启后配置一致。三平台 CI 与候选容器工件验证仍待执行，不以本地结果代替。旧候选的不可变验证记录保留在对应 GitHub Release，不把旧结果当作新版本通过。

## 人工验收边界

本机 Clash Verge 的首次导入、实际订阅更新、同 URL 刷新、改绑、链接替换和真实代理连接仍需人工验收。设备远程下载成功与服务器结构校验不同。真实 Pocket ID 接入、部署和资源情况属于部署方私有运维记录，公开产品文档不保存个人身份或域名。

Windows 仅用于开发/本地使用；生产 Linux 使用受限原生校验进程。源码提交、推送、构建、发布、部署及人工验收分别报告。
