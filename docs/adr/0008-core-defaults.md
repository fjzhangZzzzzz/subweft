# ADR-0008：保留内核默认行为

状态：已接受。此决策替代 ADR-0007 中默认直连的规定。

订阅和规则集未指定更新出站时，不向设备配置写入 `proxy`，由设备按其运行模式和规则处理；明确选择直连时才输出 `DIRECT`。显式指定的节点和组继续执行静态依赖校验。跟随规则的运行时依赖取决于实际规则、网络及缓存，静态检查不能保证首次启动成功；必要时可显式选择独立出站或直连。

未指定地理数据地址、自动更新和周期时，不生成对应配置字段，由设备内核决定默认值；显式设置仍予以保留。DAT 格式及内核默认地址可以独立设置。地址和自动更新变化可能影响下载来源、网络可达性、数据新鲜度及流量；切换配置并不清除设备已有缓存。

旧版本迁移产生的 `DIRECT` 可能既来自原始显式设置，也可能是当时自动写入的默认值，现存数据库无法区分。升级保留已有值；需要依据原始配置逐项核对后人工或经授权修正，不能批量假定用户选择。升级前的发布和备份保留，变更草稿不会自动应用到设备。
