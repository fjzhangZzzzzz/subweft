# ADR-0006：按日常任务组织工作台

状态：已接受。

## 决定

主导航为订阅、节点、配置、设备、设置。订阅与手工节点共享；策略组和有序分流规则属于各自配置。规则集是可选的内容复用能力，地理数据、用户和诊断放入设置，规则编辑时可就地管理规则集。

规则与组使用紧凑列表和独立短表单；兜底去向固定在末尾。高级字段仍提供结构化输入，常用字段不展示机器键。弹窗固定标题与操作区，Esc、点外部和关闭按钮统一执行未保存保护。

保存修改只保存草稿；应用更改可以先保存，再执行原生校验并发布。失败保留活动发布；自动更新继续采用最近发布的定义。新配置显式选择成员，默认不加入未来订阅、第三方规则或 DNS 服务。

## 公开边界

产品只实现标准配置导入。部署方模板、路径、私有默认值与迁移脚本由部署方维护，不能进入产品源码、样例、文档、发布工件或公开开发历史。必要历史修正保留产品自身开发脉络，受限恢复资料由维护者在公开仓库之外保管。

## 验证

通过真实应用验证新建、规则与组修改、一键应用、错误保留活动发布、设备链接入口、手机长弹窗及未保存保护。真实身份提供方、客户端导入与连接仍按[人工验收入口](../human-acceptance.md)独立验收。
