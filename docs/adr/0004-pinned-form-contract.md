# ADR-0004：固定版本的字段与表单契约

状态：已接受。

## 决策与原因

以锁定的 Mihomo v1.19.33、commit 和源码归档摘要为依据，提取字段名与类型事实，经产品审阅覆盖自定义标量、敏感字段和服务自管字段，保存为 [catalog.json](../../internal/fields/catalog.json)。导入、管理 API、编译和结构化表单复用这一份契约；提取工具不编译、链接或复制上游实现。

高级参数使用具体字段和类型，没有不透明 YAML/JSON 编辑出口。动态映射使用键值条目及明确的值类型表单。保留开发预览数据库已有字段表示，读入时规范化；未知字段、重复字段和错误类型明确拒绝。

## 后果

目录只能证明字段与类型覆盖，不能证明所有参数组合或真实连接。发布仍需独立固定内核校验；升级内核时重新生成并审阅目录及安全覆盖。证书与 TLS 私钥只允许内联内容，不能引用服务主机任意文件。
