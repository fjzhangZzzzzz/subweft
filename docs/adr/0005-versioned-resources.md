# ADR-0005：SQLite 内的不可变资源与设备授权

> 远程刷新与缓存、自动发布及上游凭据边界已由 [ADR-0007](0007-device-managed-updates.md) 替代；本页保留决策演进记录。

状态：已接受；扩展 [ADR-0003](0003-initial-slice-storage.md) 的首个实现边界。

## 决策与原因

规则、地理数据及按组筛选的节点 provider 以 SHA256 寻址，加密保存在同一 SQLite。发布保存完整资源清单、方案定义和配置，并在同一事务内切换活动指针；不存在另一份可编辑静态目录。资源先准备和校验，再提交引用，失败不改变有效版本。

设备配置入口稳定；资源入口绑定设备 Token、不可变发布和资源名。每次下载检查设备、有效期、使用者授权和方案归属；旧发布仅可读取仍保留且属于同一方案的资源。改绑、轮换、暂停和吊销同样作用于关联资源。

## 后果

每方案保留最近 20 版及活动版本；资源去重，保留现行缓存及历史引用，未引用资源经过 24 小时宽限后清理。单资源 64 MiB、一次校验资源合计 128 MiB、加密资源存储 1 GiB，上限失败保留现行发布。一致性 SQLite 备份包含全部资源，主密钥另行保护。

自动发布只编译最近已发布的方案定义及新的有效缓存，不激活后来保存的草稿。客户端 provider 的代理、间隔和健康检查与服务端抓取设置分开，客户端只访问鉴权资源，不取得上游 URL。
