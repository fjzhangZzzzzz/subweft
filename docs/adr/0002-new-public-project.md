# ADR-0002：新公开项目采用新历史和新入口

状态：已接受。

## 决策

Subweft 是独立的公开产品仓库，从自身首次开发起保留正常历史。不包含部署方的源码、历史、运行数据或私有迁移约定；部署和数据迁移由使用者独立维护。

使用新的独立子域名和重新设计的URL，不保留旧下载路径、认证或CLI兼容层。旧设备需要登记新链接并在实际客户端验收。配置数据和有效业务行为仍须完整迁移。

新自有内容采用Apache-2.0。新历史不消除旧内容的署名和许可义务；复用前核实代码、模板、规则和依赖来源。产品公开仓库不包含私有部署标识、凭据、真实配置、数据库或原始运行证据。

## 后果

能够统一设备授权和资源路由，减少兼容层。切换期间保留旧服务作回退，新服务独立验收；成功后退役旧生成和Git/Webhook链路。详细生命周期见[设计](../design.md)，验收见[标准](../acceptance.md)。
