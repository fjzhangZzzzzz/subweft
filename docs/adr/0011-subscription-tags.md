# ADR-0011：以标签替代固定订阅池

## 状态

已接受

## 背景

旧模型将订阅限制为 `quality` 或 `quota` 两个固定池，策略组只能引用这两个池。该模型把个人当前习惯固化为产品概念，难以表达多个用途、后续扩展和导入配置。

## 决策

- 订阅保存零个或多个自定义标签；没有自定义标签时系统派生 `未分类`。
- 策略组保存零个或多个标签，多个标签按 OR 匹配。
- `未分类` 是系统保留标签，可被策略组选中，但不能由订阅表单手工创建、重命名或删除。
- 标签直接在订阅表单中输入；重命名、合并和删除从策略组标签选择器进入，不增加独立标签管理页。
- 标签变更先写入草稿，影响预览和最终差异检查沿用现有发布流程。标签重命名、合并和删除从“订阅 → 标签”页进入；策略组编辑保留“管理标签”快捷入口。
- 新版本首次启动执行一次性迁移：`quality` → `高质量`、`quota` → `高流量`；无法识别的值归入 `未分类` 并记录迁移提示。

## 后果

- 产品不再维护固定池枚举，策略组和订阅可以按用户用途自然扩展。
- 导入配置不再推断两个池；订阅和策略组先归入 `未分类`，由用户补充标签。
- 未知迁移值可能扩大或缩小策略组来源，因此启动后展示迁移摘要，并要求用户在发布前检查草稿差异。
- 迁移完成后不保留长期兼容层；旧字段仅用于一次性读取和转换。
