# 地理数据校验边界

接受：2026-10-31。GeoDB 是可选的服务端校验条件，不是配置管理与发布的必要业务依赖。默认发布必须通过字段、引用、循环检查及固定 Mihomo 的受限原生检查；缺库时仅对已识别的地理条件构造私有投影，明确记录未验证项，允许发布原始工件。

投影不验证分类存在性、数据库加载、地理匹配效果、客户端数据或网络。提供数据库时执行相应原生加载检查；失败不会静默降级。未识别的地理表达式拒绝，不扩大现有表单支持范围。HTTP provider 内容及真实连接始终由客户端确认。

检查身份包含原生工件、策略版本和数据库摘要；检查报告绑定原始内容摘要，随发布保存。旧发布无报告表示没有此项历史证据；重启后重新检查。禁止请求时下载 GeoDB，不建设数据更新服务。部署补库保留为可选路径，不自动激活。

匿名下载在无活动发布时保持统一 404；登录设备页明确提示原因并禁用查看链接，已有授权在首次发布后继续使用。
