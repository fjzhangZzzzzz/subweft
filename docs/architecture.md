# 架构

状态：ADR-0008 正式服务已实现并进入本机验收；旧模块保留追溯，不作为服务入口。

## 服务边界

Go 服务提供 OIDC 管理入口、唯一配置的草稿与发布 API、设备授权下载及内嵌 Web UI。SQLite 是唯一业务权威；部署负责程序、独立加密密钥、OIDC 配置、固定 Mihomo 工件与 GeoDB。

管理表单 → 身份与 CSRF → 字段校验 → 加密草稿 → 纯配置编译 → 受限原生校验 → 不可变发布 → 当前发布指针 → 设备下载。

无订阅抓取器、节点标准化、缓存刷新调度或自动发布；不提供多配置、用户角色管理、旧业务路由兼容或 Git 同步。客户端直接读取远程 HTTP provider。OIDC 出站连接仍必须满足部署允许范围与超时限制。

## 持久化与并发

草稿、发布定义、编译工件和可恢复凭据加密存储。业务事务以预期修订进行比较交换。配置更新、检查记录和发布指针变化串行协调；设备授权独立保存，不使配置检查失效。

发布绑定草稿修订、内容摘要和校验器身份。原生检查不持有数据库写事务；检查返回时再次核对修订。发布事务原子保存快照、工件和活动指针。重启不得复用缺乏有效身份或完整工件的检查结果。

设备下载只读取当前已发布工件，绝不访问上游。设备 token 使用高熵随机值，查询使用带密钥摘要，可恢复明文加密；每次请求验证暂停、撤销、有效期和轮换。下载记录仅用于最近下载，不代表在线。

## 编译与校验

编译为纯函数，输入完整草稿，输出确定性 YAML 和结构化引用错误。名称、格式、数量和长度限制由服务器强制执行；未知字段拒绝。生成 provider 名称可读，内部引用使用稳定标识。规则顺序不得为方便序列化而改变。

复用固定工件摘要的独立 Mihomo 校验器。原生校验限制网络、文件、内存、CPU、时长、进程和并发。GeoDB 由部署预备，缺失时明确阻止检查，不由请求触发下载。不把远程 provider 内容未验证解释成已经验证。

## 身份与敏感数据

只有部署指定的 issuer + sub 可以管理；登录成功不自动授权。管理写操作要求有效会话、来源检查与 CSRF。管理日志不得包含 token、设备 URL、订阅地址和原始校验输出。配置预览和差异脱敏，但秘密字段变化仍可识别。Nginx 仅负责 TLS、反代和传输限制。

## 开发与切换

先使用新的本地开发数据目录，不对旧生产数据库原地转换。保留已拒绝实现的工作区改动供追溯，不将其视为新功能。第一次迁移显式导入定义并审阅差异；随后数据库独占业务权威。新旧服务分离，真实客户端验收通过后再制定切换与回退步骤。
