## 建议评审路径

页面右上角「试用指南」提供四条路径，也可直接自由操作。

| 路径 | 关注的体验 |
|---|---|
| 新增订阅并发布 | 名称、链接、订阅池是否足够；保存与发布的区别是否清楚 |
| 混合条目与分流 | 在同一用途中添加域名和 IP 是否自然；规则集、策略组和规则的分工是否易懂 |
| 空来源与修复 | 禁用唯一来源后能否定位问题；修复前是否清楚知道旧发布仍有效 |
| 设备授权 | 创建、暂停、恢复、撤销、更换链接是否直接；是否清楚其立即生效 |

附加交互包括规则排序、批量条目检查、被引用对象删除、表单放弃确认、历史恢复为草稿。试用指南内还可模拟检查过期和发布失败。

本轮浏览器检查只验证原型交互和布局。正式服务的持久化、并发、权限、密钥管理、Mihomo 原生校验、线上部署和真实客户端接受度不属于原型验证结果。
