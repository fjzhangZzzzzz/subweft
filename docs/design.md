# 产品设计

本文是已确认的实施依据。它定义目标行为，不表示功能已实现。覆盖范围见[支持矩阵](support-matrix.md)，实现完成须满足[验收标准](acceptance.md)。

## 定位与边界

Subweft 面向个人及家庭。原生接入标准 OIDC，首先验收 Pocket ID；服务管理订阅、节点、组、规则、渲染、发布和设备授权。Nginx仅做HTTPS基础反代，不保存业务Token或生成配置。基础设施运维继续由部署方的既有工具承担。

不建设开放注册、计费、多租户运营体系、复杂权限平台、插件执行平台或供设备使用的代理内核。不要求同时支持其他配置内核。新域名、新URL，不兼容旧链接、认证或命令。

## 对象和归属

| 对象 | 内容和归属 |
|---|---|
| 订阅 | URL、标签、启停、服务端抓取设置、更新计划、有效快照和健康状态 |
| 来源节点 | 从订阅解析的节点，保留源字段；本地显示名称、排除和备注独立存储 |
| 手工节点 | 通过协议表单维护，或从来源节点复制后独立维护 |
| 配置方案 | 独立拥有组、规则序列、DNS及其他客户端参数；可以复制，不做多层继承 |
| 策略组 | 属于方案；组合订阅、动态标签来源、节点和其他合法组 |
| 规则集 | 可复用自建内容或受管理的外部公共规则资源 |
| 发布版本 | 方案、采用的来源和规则快照、生成工件及校验结果的不可变集合 |
| 设备 | 归属于使用者，绑定一份方案，拥有独立下载凭据和状态 |

订阅和手工节点是共享来源；方案之间的组和规则编辑相互独立。删除被引用资源时显示影响范围并拒绝破坏性删除，提供改绑或停用路径，不静默级联删除。

## 来源与节点

接收约定范围内的 Clash/Mihomo provider YAML、完整配置中的节点、常见代理URI列表及Base64编码。支持链接、上传文件和粘贴输入，设置体积、数量和解析时间限制。

完整配置默认只提取节点；导入方案、DNS或规则必须经过单独的字段检查和预览。未知类型、字段和解析错误逐项报告，不静默跳过，不依赖公共转换服务。

来源节点的服务器、协议和凭据随上游刷新。本地名称、排除和备注与源内容分离；无法可靠匹配时提示重新关联，不凭重名套用。协议参数需要修改时复制为手工节点，不做双向合并。

标签取代固定订阅池。组既可明确选择多个订阅，也可选择全部或匹配标签的订阅。筛选节点是独立步骤，支持包含、排除及可预览的高级条件。展示每个成员的来源和命中原因。订阅前缀用于消除跨来源重名，重命名和覆盖只能应用一次。

服务端抓取代理、超时、重试和更新周期与客户端设置分开。旧provider的缓存路径、抓取出站和健康检查属于客户端Mihomo语义，不机械映射为服务端参数；仍有意义的受支持字段须在对应表单表达。

## 配置与规则

策略组可包含多个订阅、标签来源、手工节点和其他合法组。验证重名、保留名、循环、无效引用和空结果；发布前展示最终成员。空结果不自动改为直连，必须存在明确、有效的处理方式。

方案拥有一份明确有序的规则列表，混合单条规则、自建规则集、公共规则集、GEOIP及兜底规则。条件、参数和目标由类型化表单输入；支持批量、复制、启停、搜索及键盘可操作的排序。复杂条件采用条件组。兜底固定在末尾。

规则集维护内容，方案决定引用位置和目标。DNS、fake-ip及其他受支持客户端参数全部提供表单，高级字段按需展开。YAML可只读预览和导出，不作为缺失表单能力的编辑出口。

## 更新与发布

手工编辑保存草稿；发布执行结构、引用、来源、规则及固定内核校验，通过后原子切换。自动更新也经过同一保护流程。设备请求只消费已发布工件，不阻塞等待上游。

来源更新失败且存在有效快照时继续使用旧快照，显示失败原因和缓存时间；用户可在明确提示后发布其他修改。首次来源无有效内容时不能用它完成首次发布。空组、非法引用或内核校验失败阻止本次发布，不破坏现行版本。

发布记录采用的来源、规则资源和配置快照；回滚恢复对应集合。下载配置和其资源通过版本关联，避免一次发布中混用资源。历史保留需要有界、可观测，当前有效版本和可回滚版本的必要资源不得被清理。

## 设备与身份

设备链接默认长期有效，可设置到期，支持暂停、恢复、吊销及轮换。普通发布或切换方案保持URL稳定；轮换创建新链接，默认立即废止旧链接。Token及资源下载权限贯穿主配置、provider和规则资源。

管理员可再次复制已建链接，因此敏感值采用可恢复加密而非只存不可逆摘要。界面默认遮蔽。加密密钥在SQLite外保存，恢复必须同时具备数据库、必要工件和密钥。

OIDC以issuer和稳定sub识别用户。管理员维护业务，使用者只访问被授权方案和自己的设备，不查看上游凭据。首次登录不自动获得管理员。管理写请求执行授权、CSRF防护和并发版本检查。

IdP故障不影响有效设备下载现有发布；新管理登录可能不可用。应急处理归受限运维路径，不新增公网密码恢复平台。设备吊销不收回已下载的节点凭据，最近下载不代表客户端已应用或节点连通。

## 界面

桌面优先，首版中英文、默认中文；浅色、深色、跟随系统。导航为概览、来源、配置方案、规则集、设备、系统。组成员以多选、搜索和预览维护，关系图只作辅助。

常用字段直接展示，高级字段渐进展开，所有输入有标签和具体错误。失败保留输入；多错误提供可定位的摘要。可拖动操作提供按钮和键盘替代。区分草稿、已发布、最近下载、来源抓取和真实连接状态。

## 迁移与完成条件

从实际有效配置建立语义对照，纳入CLI未暴露但确实使用的字段。已退役功能和失真文档不自动成为范围。

策略组显式选择订阅、节点及其他组，不预设部署方规则。

迁移到独立实例，使用新子域名和新设备链接，在本机Clash Verge验收后才评审生产切换。旧服务保留作回退，验收后退役旧CLI、Webhook和Git推送渲染。公开开发不表示已发布、已部署或已完成替代。
