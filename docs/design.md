# 产品设计

状态：2026-10-30，依据已通过用户评审的 ADR-0008 与原型制定。正式实现已进入本机人工验收，支持与验证状态见 status.md。

## 对象与导航

导航固定为概览、订阅、策略组、规则集、分流规则、发布记录、设备。单管理员通过部署指定的 OIDC issuer + sub 登录，维护唯一配置。

订阅保存可读名称、HTTP(S) 地址、启用状态、所属高质量池或高流量池、客户端更新间隔、节点名前缀、健康检查和拉取代理。订阅恰属一个池；服务不读取上游内容。

策略组选择一个或两个池，支持 select / url-test，可加入 DIRECT / REJECT。不支持手工代理节点、组嵌套和逐节点维护。两个池同时选中表示全部订阅。

规则集分为自维护规则集、远程规则集。自维护集合按用途命名，可混合完整域名、域名及子域名、IPv4/IPv6 CIDR。选择类型后展示对应编辑提示并校验。远程集合支持 HTTP(S)、YAML、domain / ipcidr，由客户端加载。

分流规则独立设置匹配条件、目标策略、顺序；支持 RULE-SET、DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD、IP-CIDR、GEOIP。MATCH 兜底固定最后。策略组与规则集不按同名自动绑定。

## 编辑与发布

唯一持久草稿有单调递增修订号。保存要求字段格式正确；跨对象缺失、空组和空集合允许保存，发布前必须修复。所有写入带预期修订，冲突返回明确错误且保留表单输入。

新建规则时就地新增策略组，两者一次保存；取消不残留对象。删除被引用策略组时一次替换引用并删除；被引用规则集禁止直接删除。

检查与发布页面提供变更摘要和配置差异。差异支持左右对照、行内对比、行号、增删标识、修改文字高亮及上下文折叠。敏感地址不展示明文，地址变化仍明确标记。

检查绑定草稿修订和固定校验器身份，检查后编辑使结果失效。发布只接受同一修订的有效检查结果，保存不可变快照并原子更新当前发布指针。失败保留旧发布及草稿。历史恢复只生成新草稿，随后检查并发布新版本。

## 渲染

proxy-provider 使用订阅可读名称。自维护集合自动生成非空的 用途-domain 与 用途-ipcidr inline provider；规则引用在全局当前位置相邻展开，域名在前、IP 在后。生成名称冲突阻止发布。迁移须展示旧交错顺序变化，不能宣称自动语义等价。

基础端口、DNS 等首次导入后只读，随快照保存，不提供任意 YAML 编辑器。远程内容及实际连接由客户端确认，原生配置检查通过不表示节点可用。

## 设备

设备有独立名称、授权、可选有效期、最近下载时间。新增、暂停、恢复、撤销和更换链接立即生效，与草稿分离。全部设备下载同一个当前发布版本。更换后旧链接立即失效；撤销不可恢复原链接。最近下载不表示在线或已经应用。授权由 Subweft 管理，不由 Nginx 管理。

## 验收边界

独立原型已通过用户评审；正式服务已完成本机自动测试与浏览器验证。用户签收、真实客户端和生产切换须另行验收。
