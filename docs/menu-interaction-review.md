# 更多菜单交互修复

2026-11-01：统一修复当前编辑器六个列表的更多菜单：订阅、策略组、规则集、分流规则、发布记录、设备。

- 点击或触摸外部关闭，不阻止目标区域操作；同一时间仅打开一个菜单。
- 选择菜单项先关闭，再执行原操作；打开抽屉或确认框后不遗留菜单。
- Enter / Space 打开并定位首项，方向键及 Home / End 移动焦点；Esc 关闭并返回触发按钮；Tab 移出及窗口失焦关闭。
- 手机导航支持外部点击、Esc 和焦点离开关闭，展开状态同步到触发按钮。
- 高级设置等内容折叠区不受影响；编辑抽屉保留未保存确认，确认框不通过外部点击执行确认。

验证：真实 Chromium 桌面 1440×900 与手机尺寸 375×812；通过浏览器请求拦截提供合成列表数据，不修改已有业务数据。六类菜单逐页通过外部关闭、互斥、Esc 焦点返回、键盘打开与 Tab 离开测试。另验证规则集编辑抽屉及取消删除确认、手机导航关闭、触摸 pointerdown 关闭。测试脚本为 `tools/editor_menu_check.js`，在已登录的独立本地环境中使用 Playwright CLI 的 run-code 执行。触摸事件为浏览器合成事件，未宣称实体手机验收。

复查中修正了焦点离开判断过早的问题：等待浏览器完成焦点转移后再判断菜单归属，避免菜单项点击被提前关闭干扰。最终前端生产构建及交互回归通过。
