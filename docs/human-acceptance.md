# 人工验收入口

本版按已通过原型实现真实单配置编辑器，供本机试用，尚未替代生产。

## 打开

运行 `python tools/dev.py` 后打开 <http://127.0.0.1:18884/>，选择 OIDC 登录并以测试管理员继续。停止时 Ctrl+C；再次启动保留草稿和发布。启动方式及隔离目录见[本地运行](running.md)。示例使用保留域名，不具备真实代理连接能力。

## 建议按这个顺序试用

1. 新环境在概览选择“首次导入配置”，选择 [editor.yaml](examples/editor.yaml)，预览后导入。已有验收数据可以直接从订阅开始。
2. 在订阅修改名称、所属池；策略组选择两个池。在规则集中给“AI”增加 `192.0.2.0/24`，确认类型切换时输入提示对应变化。
3. 在分流规则关联“AI”集合与策略组，调整顺序。保存后刷新，确认草稿仍在且当前发布没有改变。
4. 打开“查看变更并发布”→“配置差异”，切换左右/行内对比；仅修改订阅地址也应看到脱敏的新旧差异。
5. 检查配置，通过后发布。创建一个设备，复制链接并下载，确认 provider 名称可读且混合规则集正确展开。
6. 编辑但不发布，再下载仍应是旧版本。暂停设备后下载失败，恢复后成功；更换链接后旧地址失效。
7. 发布记录恢复旧版本：仅生成草稿，重新检查并发布才更新设备。放弃草稿同样不影响设备授权。
8. 窄屏检查导航、表单、差异与确认弹窗；检查时按钮不能重复提交。

如需试用自己的订阅，先确认本机环境和密钥保存妥当。设备链接不要提交到仓库、截图或问题报告。当前导入范围见[支持矩阵](support-matrix.md)，不支持的旧配置需先整理为支持的子集。

## 记录反馈

提供操作位置、输入类型、预期与实际结果即可；不需要提供 token 或完整订阅地址。真实 Pocket ID、真实订阅连通性和 Clash Verge 接受由人工另行确认，本机测试身份与保留域名无法证明这些结果。
