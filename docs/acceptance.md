# 单配置编辑器验收标准

入口和步骤见[人工验收](human-acceptance.md)。原型通过不替代正式服务验收。

1. 导航与已通过原型一致：概览 → 订阅 → 策略组 → 规则集 → 分流规则 → 发布记录 → 设备；桌面和手机可完成主操作。
2. 从空配置导入支持的 YAML，预览数量后保存草稿；未知字段/错误类型/多文档不得默默忽略。首次未发布状态明确不可下载。
3. 表单修改刷新后保留；错误不丢输入；另一会话保存后旧修订提交失败。
4. 用途集合混合 domain/IP；生成可读 `用途-domain`、`用途-ipcidr`，保持全局位置和 no-resolve 边界；引用错误、空组、循环、生成名冲突阻止发布。
5. Git 风格差异有行号、增删、文字变化、上下文折叠；仅改 URL 也能辨认新旧，不能出现真实地址。
6. 原生检查绑定当前修订；检查后编辑必须重检。检查/发布失败时设备仍下载原发布。
7. 发布后设备取得新工件；历史恢复、放弃草稿都恢复服务端完整定义与秘密，不直接改当前发布。
8. 设备暂停、恢复、到期、撤销、轮换立即影响后续下载；设备操作不使草稿检查失效。
9. 匿名和非指定管理员不能访问管理 API；所有管理写操作校验 CSRF；旧业务路由不存在。
10. 重启保持草稿、发布、设备及有效 token，但不能复用重启前检查；下载不访问上游。

人工签收另验证 Pocket ID、实际订阅、真实 GeoDB、Clash Verge 更新和连接；必须区分成功渲染、原生检查、实际连接与真实客户端接受。开发期禁止修改生产。

11. 缺 GeoDB 的 MMDB/DAT/GEOIP 及 DNS GEOSITE 检查明确标记未验证，必需检查通过后发布原始规则；错误语法、目标、循环及其他原生错误仍阻止发布。数据库变化使检查身份变化，损坏数据库不得自动降级。
12. 无活动发布时设备授权可预先建立，登录设备页禁用查看链接；匿名请求不披露授权或发布状态。首次发布后同一授权可下载。

13. 概览标题区可打开基础配置；DNS 预设仅填充表单，取消不保存。DNS 编辑保存后产生差异、使旧检查失效，发布前不改变活动配置。未编辑字段、字符串/数组类型及缺省值保持原样；服务端拒绝运行设置、未开放 DNS 字段及错误类型修改。
